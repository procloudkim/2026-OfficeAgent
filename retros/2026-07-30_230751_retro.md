## KPT 회고

### Keep (좋았던 것)

- 실제 임시 PostgreSQL database와 pgvector를 사용하는 Compose 테스트로 SQL predicate, transaction과 rollback을 함께 검증해 mock만으로는 놓칠 수 있는 저장소 경계를 확인했다.
- 캐시 무효화 이후 실패까지 주입함으로써 정상 경로뿐 아니라 stale cache 재생성과 부분 상태가 남는 위험을 직접 다뤘다.
- prompt version을 단일 정본으로 만들고 세 버전 일치를 캐시 조건으로 강제해 설정 변경 후 오래된 답변이 재사용되는 범위를 줄였다.
- JSON envelope와 delimiter breakout 회귀 테스트를 함께 추가해 프롬프트 구조 계약을 코드와 테스트로 연결했다.
- offline SSE 성공과 실제 Codex delta 증거를 구분해 현재 검증 범위보다 넓은 완료 주장을 하지 않았다.

- offline SSE 테스트는 실제 Codex 호출이나 토큰 delta 전달을 증명하지 않는다.
- JSON 직렬화는 delimiter 구조 이탈을 막지만 의미적 prompt injection 안전성이나 답변 entailment를 검증하지 않는다.
